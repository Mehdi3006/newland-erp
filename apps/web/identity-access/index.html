P3.2 Identity & Access

Identity administration

Contract-first administration surface for authentication, authorization, scoped roles, sessions, and password operations.

Login Users Roles Permissions Assignments Profile Sessions Change Password

Login

Uses /api/v1/auth/login for JWT access tokens and refresh tokens.

Users

Create, update, read, and list IAM users. No employee or HR data is modeled here.

Roles

Roles are capability containers, not hardcoded administrator switches.

Permissions

Capabilities use dotted names such as identity.user.manage.

Assignments

User-role assignments include enterprise, legal-entity, company, branch, or warehouse scope.

Profile

Current-user profile and account metadata contract placeholder.

Sessions

Session list supports revocation and device tracking readiness.

Change Password

Passwords are validated by policy and stored only as Argon2id hashes.

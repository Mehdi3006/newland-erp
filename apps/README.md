# Applications

This directory is reserved for future independently deployable applications. Phase P1 permits no
application source, framework configuration, page, controller, endpoint, or runtime package here.

A future application requires an accepted ADR, named owner, threat model, operational runbook, build
target, tests, and release path. Follow
[`docs/architecture/module-onboarding.md`](../docs/architecture/module-onboarding.md).

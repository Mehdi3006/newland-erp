# Domain Map

The domain map groups Newland ERP responsibilities into bounded contexts. A bounded context is not a
menu item. It is an ownership boundary for language, rules, data, and transaction consistency.

## Context Grouping Principles

- Enterprise Structure is the anchor for company, branch, warehouse, and reporting scope.
- Product Information Management owns product truth; Procurement, Sales, Inventory, Service, and
  Website integrations reference it.
- Inventory owns stock truth; Sales and Procurement request stock changes rather than editing
  balances.
- General Ledger owns accounting truth; source contexts publish accounting-relevant facts.
- Workflow owns approval process state, not source transactions.
- Reporting consumes owned data; it does not become a shadow owner.

## Reporting Rules

- Reports must state source data owner.
- Reports cannot create source transactions.
- Measures must be defined before dashboard implementation.
- Export must be permissioned and audited.
- Sensitive financial, HR, customer, supplier, and bank data requires restricted access.

## OPEN DECISION

- BI semantic layer technology.
- Near-real-time refresh requirements.
- Executive KPI definitions.
- Margin and landed-cost reporting formulas.

## Event Rules

- Events describe facts that already occurred.
- Event payloads should contain identifiers and minimal facts, not full documents.
- Sensitive fields require explicit classification before inclusion.
- Consumers must be idempotent.
- Ordering is guaranteed only within explicitly documented aggregate or document streams.
- Retry behavior must not create duplicate business effects.

# Decision Records

Decision records capture significant but non-architectural choices such as a time-bounded tool
exception, rollout sequence, or operational default.

Use an ADR instead when the choice changes a system boundary, supported technology, security model,
persistent data model, or cross-team contract.

Copy [`decision-template.md`](decision-template.md), name the file `YYYY-MM-DD-short-title.md`, and
link it from the affected issue or pull request. Records must include an owner, expiry or review
date, and outcome.

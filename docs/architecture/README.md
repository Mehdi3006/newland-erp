# Architecture

This directory describes the current architecture of the repository. It does not authorize ERP
business implementation.

- [`repository-layout.md`](repository-layout.md) defines directory boundaries.
- [`module-onboarding.md`](module-onboarding.md) defines the approval and integration sequence for
  future modules.
- [`quality-gates.md`](quality-gates.md) maps local and CI controls.
- [`file-catalog.md`](file-catalog.md) explains why foundation files exist.
- [`phase-p1-scope.md`](phase-p1-scope.md) records the current delivery boundary.
- [`foundation-dependency-graph.md`](foundation-dependency-graph.md) maps the order of foundation
  capabilities.
- [`foundation-risks.md`](foundation-risks.md) tracks foundation risks and mitigations.

Material changes to these documents require an ADR and architecture-owner review.
